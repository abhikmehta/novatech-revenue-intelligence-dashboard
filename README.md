# NovaTech Solutions — Revenue Intelligence Dashboard

**Analyst:** Abhik Mehta | **Stakeholder:** Sarah Chen, VP of Revenue Operations
**Platform:** Amazon Quick (Enterprise), Quick Index, Quick Chat (Q), SPICE

## Problem
NovaTech's revenue data sits in three separate systems: CRM deals, marketing campaigns and support tickets. This project joins them into one interactive dashboard covering the customer journey from marketing touchpoint to closed deal to support experience.
